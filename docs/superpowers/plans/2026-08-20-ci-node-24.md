# Update CI/CD to Node 24 Implementation Plan

For agentic workers: REQUIRED SUB-SKILL — `superpowers:subagent-driven-development` and
`superpowers:executing-plans`. Read both before executing this plan. Check off each `- [ ]` step as
it is completed.

## Goal

Resolve GitHub Actions Node version deprecation warnings by pinning Node `24` instead of `22` in
the `cloudflare-pages` job of `.github/workflows/deploy.yml` (and any other workflow that pins Node).

## Architecture

No architectural change. This is a CI configuration pin update only — the frontend Svelte SPA
(`web/`) and its `npm` toolchain are unaffected. The only place Node is pinned in CI is the
`actions/setup-node@v4` step in `deploy.yml` (`node-version: 22`); `bump.yml` and `release.yml`
do not pin Node.

## Tech Stack

GitHub Actions workflow YAML. No Rust, no Svelte changes.

## Spec

Fast-path: no design spec per light-factory-development trivial-task criteria — single-file CI
config pin change with no new public interface, no behavior change, and a one-sentence acceptance
criterion.

## Global Constraints

- All work happens in the worktree `.worktrees/ci-node-24`; never commit to `master` directly.
- No AI/Claude attribution in commit messages, PR bodies, or docs.
- No change to dependency flow, wire types, the auth spine, or the deploy/distribution shape
  (`Dockerfile`, `fly.toml`, `web/`, `crates/persistence/migrations/`) beyond the CI pin.

## Out-of-band verification

The change touches `.github/` (CI workflow). The check is YAML validity (done above) — GitHub
Actions itself cannot be run locally; the workflow's `node-version` warning resolves on the next
CI run.
